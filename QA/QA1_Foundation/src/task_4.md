### Тестирование в разработке


| Уровень тестирования | Кем проводится | На каком этапе жизненного цикла ПО | Процесс проведения |
| - | - | - | - |
| Модульное |Разработчики |Во время разработки | Тестируются отдельные функции/классы/методы. Используются фреймворки (JUnit, pytest). Может быть ручным, но чаще автоматизированным.|
| Интеграционное |Тестировщики/разработчики |После модульного тестирования | Проверяется взаимодействие модулей/сервисов. Может быть: <br>- Снизу вверх (Bottom-Up) – сначала тестируются низкоуровневые модули. <br>- Сверху вниз (Top-Down) – сначала тестируются высокоуровневые модули. <br>- Сэндвич (Sandwich) – комбинация обоих подходов.|
| Системное |QA-инженеры | После сборки полной версии ПО|Проверяется работа системы в целом: <br>- Функциональное тестирование. <br>- Нагрузочное тестирование. <br>- Тестирование безопасности. <br>- Тестирование совместимости. |
| Приемочное |Заказчик/QA-инженеры | Перед релизом| Проверяется соответствие требованиям заказчика: <br>- Alpha-тестирование (внутри компании). <br>- Beta-тестирование (ограниченный круг пользователей). <br>- UAT (User Acceptance Testing) – тестирование конечными пользователями.|
