## 1. Изучение ресурса ISTQB

1. [ISTQB](<https://www.istqb.org/>) — это международная организация, которая разрабатывает и поддерживает стандартизированные программы сертификации для специалистов в области тестирования программного обеспечения.
### Функциональность сайта
    - Сертификации
    - учебные материалы
    - Поиск аккредитованных учебных центров 
    - Подготовка к экзаменам

Сайт **ISTQB** полезен для тестировщиков, желающих подтвердить свою квалификацию.

### 2. Назначение разделов «Certifications», «SCR» и «Glossary».

 1. [«Certifications»](<https://www.istqb.org/certifications/>) - Основной каталог всех сертификаций ISTQB с фильтрацией по уровням и специализациям.

Помогает:

- Найти специализированные сертификации.
- Скачать учебные материалы.
- Перейти к поиску аккредитованных экзаменационных центров.

Скриншот раздела «Certifications»
![task_1_2](misc/images/task_1_2.png)

2. [«SCR»](<http://scr.istqb.org/>) - Данный раздел позволяет проверить сертификаты успешных кандидатов. Владельцы сертификатов, будут указаны с анонимизированным номером сертификата. Эта функция предоставляет достаточно информации для проверки номера сертификата, предоставленного пользователем.

Скриншот раздела «SCR»
![task_1_3](misc/images/task_1_3.png)

3. [«Glossary»](<https://glossary.istqb.org/en_US/search?term=&exact_matches_first=true>) - официального глоссария терминов по тестированию ПО. Содержит официальные определения всех ключевых понятий тестирования. Позволяет посмотреть определение интересующего понятия, увидеть где используется понятие в программах подготовки. Так же присутствует возможоность выбора языка.

Скриншот раздела «Glossary»
![task_1_4](misc/images/task_1_4.png)
